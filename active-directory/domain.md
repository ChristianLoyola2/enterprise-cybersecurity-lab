# Active Directory Domain

## Overview

The cybersecurity lab includes a Windows Server 2022 environment configured as a Domain Controller for a simulated enterprise network.

## Domain Services

The Active Directory environment provides centralized management of:

- User accounts
- Security groups
- Organizational Units (OUs)
- Group Policy Objects (GPOs)
- Authentication
- Security policies
- Auditing

## Core Services

- Active Directory Domain Services (AD DS)
- DNS
- Group Policy
- Security Auditing

## Domain Controller

**Operating System:** Windows Server 2022

**Role:** Domain Controller

**Services:**

- Active Directory Domain Services
- DNS
- Group Policy
- Security Auditing

## Security Objectives

The Active Directory environment is used to practice:

- Centralized identity management
- Access control
- Password policies
- Account lockout policies
- Security auditing
- Endpoint monitoring
- Integration with Wazuh SIEM

## Integration with Wazuh

Security events generated by Windows systems are monitored through Wazuh to improve visibility over authentication and security-related activity.

## Environment

This configuration is part of an isolated virtualized cybersecurity laboratory designed for educational and professional practice.
